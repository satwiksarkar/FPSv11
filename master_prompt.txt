2D TILE ARRAYS IN A 3D GAME: HOW TO ADAPT THE STORY SPEC
==================================================================

The team's story spec was written like a 2D tile game (QPainter, X/Y floats). This game is a 3D Qt Quick 3D voxel game,
so apply it like this:

* Each array cell is ONE block-sized tile on the floor grid. Use the existing block size from the master prompt
  (for example 1 tile = 1 block = 100 Qt Quick 3D units).
* Array indexing is level[row][col]. col = world X axis, row = world Z axis (row 0 is the top/north edge, so the
  "top-right corner" is row 0, col max). Y is the vertical axis in 3D. "Player X/Y float coordinates" in the story spec
  means the player's X and Z position (plus the Y camera height).
* Walls, crates, pillars and the core are stacked cubes (wall height about 3 blocks, crates 1 to 2 blocks), drawn with
  Qt Quick 3D INSTANCING. Draw only the visible surface blocks. Floors and the ceiling are single large flat boxes
  per level, not one model per tile.
* Collision for player and enemies is a cheap tile lookup (is this tile solid?), plus small circle-vs-tile pushback.
  No physics engine.
* Line of sight and shot-vs-wall tests use a simple grid ray (DDA) in C++: step through tiles along the ray until a solid
  tile is hit. Player shots take the nearest of (wall distance) and (enemy/vent hit distance), so walls always block shots,
  even if the Qt Quick 3D pick function does not see instanced wall blocks.
* Entities (enemies, pickups, Cooling Vents) are NOT stored in the tile arrays except where the spec says so. Their start
  positions are fixed lists in the level data.

TILE CODES (the team's codes plus two small additions):
  0 = empty floor
  1 = solid wall (outer boundary / reinforced steel / pillars)
  2 = stacked metal shipping crate (solid obstacle)
  3 = player spawn tile (ADDED; one per level)
  4 = Level 1 exit tile (extraction elevator)
  5 = ammo pickup tile
  6 = Level 2 exit tile (descent shaft)
  7 = heavy weapon pickup tile (ADDED; one in Level 2)
  8 = invisible trigger tile (Level 2 crossfire trap; floor, not drawn as a block)
  9 = VANGUARD core wall tile (Level 3, solid, armored)
